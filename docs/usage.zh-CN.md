# 夹心贴 1.0 使用手册

区域截图、标注和桌面贴图，适用于 Windows 与 macOS。下载地址：https://github.com/Jesseovo/jiaxintie/releases/tag/v1.0

## 安装与启动

### Windows

支持 Windows 10 / 11 x64，使用 .NET Framework 4.8。

解压 `JiaXinTie-Windows-x64-v1.0.zip`，可选两种启动方式：

1. 运行 `夹心贴-安装程序-1.0.exe`。安装向导会让你选择程序位置和截图保存文件夹，不需要管理员权限。
2. 直接打开 `夹心贴.exe`，使用便携版。首次启动时设置保存目录与快捷键。

程序启动后位于系统托盘，双击托盘图标也可以开始截图。更换版本前先退出旧程序；升级保留原有设置。

### macOS

支持 macOS 14 及以上，通用应用同时包含 Apple Silicon 与 Intel 架构。

解压 `JiaXinTie-macOS-universal-v1.0.zip`，将 `夹心贴.app` 拖入“应用程序”，然后打开。应用位于屏幕顶部菜单栏，不常驻 Dock。

首次截图时，在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”中允许夹心贴，然后按系统提示重新打开应用。较早的 macOS 版本可能将此项称为“屏幕录制”。全局快捷键、标注和贴图不需要辅助功能权限。

当前发布包使用临时签名，尚未经过 Apple 公证。请从上述仓库的 Release 下载，并使用发布页提供的 SHA-256 校验文件核对包的完整性。

## 快捷键

| 操作 | Windows | macOS |
|---|---|---|
| 开始截图 | F1 | F1 |
| 完成复制 | 再按 F1 | 再按 F1，或 Return / ⌘C |
| 保存 PNG | S | S |
| 贴图 | F3 | F3 |
| 显示 / 隐藏全部贴图 | Shift+F3 | ⇧F3 |
| 框选即复制 | Ctrl+F1 | ⌘F1 |
| 取消截图 / 删除当前贴图 | Esc | Esc |
| 撤销 / 重做标注 | Ctrl+Z / Ctrl+Y | ⌘Z / ⌘Y |
| 贴图原始大小 | 0 | 0，或双击贴图 |

Mac 如果默认把 F 键用于亮度或音量，配合 Fn 使用，也可以在 macOS 键盘设置中选择将 F 键用作标准功能键。设置默认只展示截图、贴图和保存，其他按键在“更多快捷键”中。

点击按键框后，按下想用的快捷键即可重新配置。全局按键如被其他软件占用，需要更换组合或退出占用的软件；Mac 的裸字母不能用作全局快捷键。菜单和工具栏始终可以点击操作。

## 截图与标注

按 F1 后拖动框选。初始状态可以移动选区；尚未添加标注时，也可拖动边缘或角点调整大小。

选区旁的工具栏依次提供矩形、圆形、直线、箭头、画笔、荧光笔、马赛克、文字和橡皮擦，右侧是撤销、重做、保存、贴图、取消及复制。颜色与粗细位于下方。

再次点击当前工具，或在标注模式下右键，可回到移动状态。橡皮擦移除命中的整条标注，支持撤销与重做。马赛克会进入导出的图片；发布敏感图片前，请自行检查遮挡是否足够。

选择文字工具后，在选区中点击并输入。Return 先完成中文输入法组词，再提交文字。编辑文字时，全局截图热键暂停，复制、粘贴和撤销按文本框的行为处理；S 会正常输入，不会触发保存。

按 F1 复制，按 S 保存，或按 F3 直接将当前截图贴到桌面。取消截图不会生成新缓存。保存失败时编辑器保留，方便你继续处理。

Mac 在每块显示器上分别按其缩放比例截图，并保留 Retina 原生像素；一次选区限定在一块显示器内。

## 桌面贴图

按 F3 优先读取剪贴板中的图片；没有可用图片时，使用上次截图或最近缓存。

- 拖动贴图调整位置，滚轮或触控板滚动缩放。
- Windows 使用 Ctrl+滚轮调整透明度；Mac 使用 ⌘ 或 ⌃ + 滚动。
- 右键可以复制、保存、恢复原始大小或删除贴图。
- 删除只关闭这一张贴图，不删除手动保存的图片，也不移除最近三张缓存。

“最近截图”菜单可重新打开缓存中的图片并贴到桌面。

## 保存与缓存

按 S 会直接保存 PNG 到已选择的目录，不弹出另存为窗口。

```text
你选择的文件夹/
  夹心贴-日期时间-唯一标识.png       手动保存，长期保留
  缓存/
    jxt-cache-日期时间-唯一标识.png  自动轮换最近三张
```

完成复制、保存或贴图时记录自动缓存。程序只轮换自己命名的缓存文件，不清理无关内容。更换保存目录只影响后续截图，旧文件保留。

Mac 默认目录为 `~/Pictures/夹心贴/`；Windows 安装时选择目录，便携版首次启动时设置。

设置文件位于：

- Windows：`%LocalAppData%\JiaXinTie\settings.json`
- macOS：`~/Library/Application Support/JiaXinTie/settings.json`

## 已知范围

v1.0 包含区域截图、基础标注与桌面贴图，没有 OCR、滚动长截图、自动窗口识别或复杂贴图分组。Mac 跨屏拼接尚未实现。

HDR、受保护内容、安全桌面及多显示器混合缩放不在完整交互验收范围内。测试环境与结果见仓库中的 `VALIDATION.md`。发现问题可在 https://github.com/Jesseovo/jiaxintie/issues 提交系统版本、复现步骤和不含私人内容的示例。
