# 关于夹心贴

夹心贴（JiaXinTie）是一个专注区域截图、基础标注和桌面贴图的原生桌面工具，由 [Jesse](https://github.com/Jesseovo) 维护。当前版本为 v1.0，支持 Windows 与 macOS。

它想解决一个很日常的小问题：需要对照的内容，能不能一直留在手边？

## 为什么做夹心贴

写代码时，参考界面常常在另一个窗口；画图时，配色和细节需要来回找；学习时，刚看到的一小段资料又被新窗口盖住。夹心贴把截图和桌面贴图放在一起，让这些临时参考有一个顺手的位置。

默认操作只需要记住 F1、F3 和 S：截一张，贴在旁边，或者存进自己的文件夹。其他功能也可以点击工具栏或菜单使用。

## 适合怎样的日常

- **开发与设计**：把参考界面、布局、配色和小细节放在当前工作窗口旁边。
- **学习与阅读**：把资料片段、题目和笔记临时固定，方便对照。
- **沟通与反馈**：圈出重点、添加箭头和文字，将标注后的截图复制或保存。
- **日常整理**：快速保存一张图片，需要时从最近截图里重新贴回桌面。

## v1.0 已经能做什么

| 能力 | 具体操作 |
|---|---|
| 区域截图 | 拖动框选，复制到剪贴板或保存为 PNG |
| 基础标注 | 矩形、圆形、直线、箭头、画笔、荧光笔、马赛克、文字、橡皮擦 |
| 编辑历史 | 撤销、重做；橡皮擦移除命中的整条标注 |
| 桌面贴图 | 从剪贴板、上次截图或最近缓存贴图，支持拖动和滚动缩放 |
| 贴图管理 | 调整透明度、复制、保存、恢复原始大小、隐藏和删除 |
| 本地保存 | 自选保存目录；手动图片长期保留，自动缓存最近三张 |
| 快捷键 | 默认 F1 / F3 / S，可以在设置中修改 |

## 两个平台，各自原生

**Windows** 支持 Windows 10 / 11 x64，使用系统托盘入口，提供便携程序及中文安装向导。应用依赖 .NET Framework 4.8。

**macOS** 支持 macOS 14 及以上，通用应用同时包含 Apple Silicon 与 Intel 架构，使用原生菜单栏入口和 Retina 像素导出。一次选区位于一块显示器内。

Mac 首次真实截图需要屏幕录制权限。当前 Mac 发布包使用临时签名，未经过 Apple 公证；Windows 包未配置发行者签名。安装和权限细节见[使用手册](usage.zh-CN.md)。

## 图片如何保存，数据如何处理

桌面应用没有联网、广告、遥测、账户或图片上传逻辑。截图写入你选择的本地文件夹；复制操作使用系统剪贴板。

自动缓存只轮换“缓存”子目录里由夹心贴命名的文件，保留最近三张。不删除手动保存的图片或无关文件；更换保存目录，也不清理旧目录。删除桌面贴图只关闭当前图片窗口。

产品官网用于展示、演示操作和下载安装包，不读取用户的桌面。官网的明暗模式偏好保存在浏览器本地，不作为桌面应用的用户配置。

## 当前边界与验证范围

v1.0 专注日常区域截图和贴图，尚未实现 OCR、滚动长截图、自动窗口识别和复杂贴图分组。Mac 跨显示器拼接尚未实现。

发布包经过 Windows 和 macOS 原生构建，以及图像、配置、缓存和窗口回归检查。进程内回归不替代真实屏幕、物理按键、中文输入法和多显示器交互验收。HDR、受保护窗口及混合缩放不在完整验证范围内。

具体环境和结果见[验证记录](../VALIDATION.md)，各次对外发布见[更新记录](../CHANGELOG.md)。已有的 Windows 功能和原生 Mac 实现统一按 v1.0 发布。
